# Twitter Algorithm Optimizer

Maximizes Twitter/X reach through data-driven content strategies aligned with the current algorithm.

## Algorithm Key Factors (2025-2026)

```
Engagement Weight:
1. Replies (highest weight)    → Spark conversations, ask questions
2. Bookmarks (growing weight)  → High-value, save-worthy content
3. Retweets/Quotes             → Amplification signal
4. Likes                       → Weakest signal
5. Profile clicks              → Interest signal
6. Time spent reading          → Long-form tweets matter

Negative signals:
- "Block" or "Mute" → kills distribution
- Low reply rate → penalized
- High link-out rate → algorithm pushes down
```

## Content Frameworks

### Hook Formulas (first line = everything)
```
1. Contrarian: "Everyone says X. They're wrong. Here's why:"
2. Number: "I analyzed 500 [X]. Here's what I found:"
3. Story: "3 years ago I [failure]. Today [success]. Thread:"
4. Bold claim: "The best [X] I've ever [done/seen/built]:"
5. Question: "Why does nobody talk about [X]?"
6. Secret: "What [big company] doesn't want you to know:"
```

### Tweet Formats That Win
```
Single Tweet (for virality):
- 200-250 chars optimal (leaves room for RT with comment)
- One clear insight or emotion
- Optional: relevant image (2x reach)

Thread (for authority building):
- Hook tweet: bold claim or story start
- Tweets 2-8: evidence, examples, steps
- Final tweet: summary + CTA ("Follow for more X")
- Ideal length: 5-10 tweets

Quote Tweet Strategy:
- Add your unique perspective to trending content
- Disagree respectfully with popular takes
- Bridges your expertise to wider conversations
```

## Optimization Checklist

Before posting:
- [ ] Hook is in first 10 words
- [ ] No external links in main tweet (reply with link if needed)
- [ ] Has natural engagement CTA (question, "agree?", poll)
- [ ] Under 280 chars for retweet margin  
- [ ] Posted during peak hours (6-9am, 12-2pm, 6-9pm your timezone)
- [ ] Relevant image or video attached (when applicable)
- [ ] Replies ready to go (respond in first 30 min = algo boost)

## Analytics Interpretation

```markdown
## Tweet Performance Analysis

Good engagement rates (organic):
- Impression rate: >0.5% engagement/impressions = good
- Bookmark rate: >0.1% = exceptional (save = high value signal)
- Reply rate: >0.2% = conversation-driving

Red flags:
- High likes, 0 replies → not stimulating enough
- High impressions, low engagement → hook works, content doesn't
- High replies, low reach → engaging niche, not breaking out
```
